## 可复用边界

- `runtime.py`：只创建模型函数字典，不读密钥、不调用模型、不检查无关 profile。
- `routing.py`：用可信元数据生成允许的路由。
- `execution.py`：执行路由，只在 `ProviderError` 时走计划内回退。
- `hermes.py`：通过已安装的 Hermes CLI 完成一次文字调用。
- `calendar.py`：日程数据、校验、排序和文字展示。
- `email.py`：邮件数据、本地摘要和成功/不可用两种展示。
- `briefing.py`：组织日程与多封邮件，逐封处理预期失败。
- `examples/`：构造示例数据、调用统一工厂、运行并打印结果。

新入口用法：

```python
providers = create_providers()
text = build_daily_briefing(events, emails, providers)
```

工厂返回三种可调用函数，不会立即触发三种模型。邮件业务依旧固定生成 Local-only 路由；缺少远程认证不会阻止本地摘要。
